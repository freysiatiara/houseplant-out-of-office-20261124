## The entry

> Out of office: ignored since March, alive purely out of spite. Your email? Filed under compost.

(95 characters — inside the 120-character limit.)

## How it works

`main.py` (Python standard library only) writes the line above to
`/output/entry.txt` with mode `0644`. Run it with:

```sh
python3 main.py
```
